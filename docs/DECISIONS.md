# Decisions

- 2026-09-29: The project and repository name is **ArcMandate**. The five supplied plan files and their project-name references were renamed before the first commit. This also changes the planned signature domain and keyfile identifier; fixture tests must use the ArcMandate strings.
- 2026-09-29: The implementation plan and roadmap govern current work when older planning/review documents differ.
- 2026-09-29: Solidity 0.8.28 with Paris EVM target is an initial conservative toolchain setting. Arc compatibility remains to be proven with real RPC integration before deployment.
- 2026-09-29: Vite 8 Workers use ES module output because Noble's imported modules require code splitting; the default IIFE Worker build failed. The Worker build and local browser verification passed after setting `worker.format = 'es'`.
- 2026-09-29: Arc testnet P2 succeeded with a real PQ signature and ERC20 USDC transfers. The solc 0.8.28/Paris setting is compatible with this tested path; wider network and security claims still require P6 review.
- 2026-09-29: Arc RPC `latest` briefly returned a head older than a transaction receipt from the same run. Demo simulations and state reads use the preceding receipt's explicit block number. A simulation is recorded separately from a mined transaction.
- 2026-09-30: P4 ABI and deployment bytecode are generated together from the pinned Foundry artifact with `npm run artifacts`; the web build regenerates them. Deployment is reviewed, simulated and submitted through EIP-1193 after backup restoration.
- 2026-09-30: P4 enables testnet management and mainnet read-only access. Mainnet writes remain gated until P6/P7 release checks. The frontend has no production server signer or relayer.
- 2026-09-30: Receipt and unknown-submission handling retain transaction hashes and prevent automatic resend. Context changes lock the Worker; form changes invalidate review. Live nonce/session/deadline checks read only the changing fields at one block to reduce public RPC request load; immutable owner/key are checked during preparation.
- 2026-09-30: The optional localhost smoke page injects an EIP-1193 test wallet backed by disposable testnet accounts in Node. It captures the browser's encrypted export to an ignored disk file and selects that same file in a clean page. This proves the product Worker/file/transaction path, but is not a real extension-wallet compatibility test or a literal OS Downloads/file-picker check. The smoke entry and private bridge are excluded from the production build.
- 2026-10-02: P6's clean source installation and Chrome MetaMask/Windows-picker test passed. The user waived the additional clean Git clone/build for this checkpoint. Explorer source verification requires a deployed mainnet contract and belongs to P7; actual mainnet accounts, funding and spending authorization are P7 prerequisites. P6 completion does not authorize mainnet writes or imply an audit.
